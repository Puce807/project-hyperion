# Gaia Fields Docs

This doc explains what each of the fields collected from the Gaia database are and their use in the pipeline.


| Name      | Description                                  | Use                             |
|-----------|----------------------------------------------|---------------------------------|
| source_id | Unique identifier for stars in the catalouge | Used to identify specific stars |
| ra        | The right ascention of a star                | Currently no use                | 
| dec       | The declination of a star                    | Currently no use                |
